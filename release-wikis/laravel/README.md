# Laravel Wiki publication set

Destination: `ValentinNikolaev/php-upgrade-preflight-laravel` GitHub Wiki.

The Laravel package guide becomes this Wiki's `Home.md`. Artisan, adapter internals,
shared concepts, safety, and troubleshooting are intentionally duplicated to keep
the package Wiki usable by application developers and technical managers. The
physical release copies are in `pages/` and are checksum-bound to canonical sources.
